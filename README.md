# 튼튼이 만나러 가는 길 🍼

입원·제왕절개·조리원 정보를 한곳에 모은 안내 사이트 (정적 웹사이트, GitHub Pages).
사이트: https://scepter13.github.io/tuntuni-guide/

## 구성 (한 화면 = 정보 하나, STEP 카드로 넘기기)
- 🏠 홈(NOW): D-day + 오늘 날짜(KST)에 맞는 "지금 가장 중요한 것" → **STEP 1부터 보기**
  - 시기: 준비(~11/29) · 입원(11/30) · 수술(12/1) · 회복(12/2~4) · 퇴원(12/5~6) · 조리원·행정(12/7~)
  - 위쪽 단계 아이콘을 누르면 다른 시기의 카드도 볼 수 있음
- 🎒 준비물 · 🏥 병원생활 · 🩺 회복·질문 · 💪 남편: 좌우로 밀거나 다음/이전 버튼으로 넘기는 STEP 카드
- 🍼 기록: 수유·기저귀·진통제 한 번 누르기 기록
- 날짜 미리보기: 주소 뒤에 `?d=2026-12-01` 붙이기

## 내용 고치기
- 출처·준비물·남편 할 일 원본: `data.js`
- STEP 카드 내용(시기별·병원생활·회복): `decks.js`
- 화면: `index.html`, `style.css` / 동작: `app.js`
- 내용을 바꾸면 `sw.js`의 캐시 이름(`tuntuni-vN`) 숫자를 올려 주세요.

체크·기록·메모는 각 휴대폰의 브라우저(localStorage)에만 저장됩니다.
