# 튼튼이 만나러 가는 길 🍼

냠모와 튼튼이를 위한 입원·출산·조리원 안내 사이트 (정적 웹사이트, GitHub Pages).

## 💌 편지 고치는 법 (남편용)
1. GitHub에서 `letter.js` 파일을 연다.
2. 오른쪽 위 연필(✏️ Edit) 버튼을 누른다.
3. `body:` 뒤 백틱(`) 사이의 글을 원하는 편지로 바꾼다. (`cheers:` 는 홈 화면의 하루 한마디)
4. 아래 **Commit changes** 를 누르면 1~2분 뒤 사이트에 반영된다.
5. 미리보기: 사이트 주소 뒤에 `?letter=preview#letter` 를 붙여서 열기.

편지는 2026-12-01 오전 6시(KST)부터 냠모 화면에서 열린다.
⚠️ 이 저장소는 공개라 편지 내용도 누구나 볼 수 있다. 실명·주민번호 같은 개인정보는 쓰지 말 것.

## 파일
- `index.html` 화면 / `app.js` 동작 / `data.js` 내용(준비물·일정·남편 할 일) / `letter.js` 편지
- 체크·기록·메모·사진은 각 휴대폰의 브라우저(localStorage)에만 저장된다.
